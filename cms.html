Posts

How publishing works:
1. Write or edit posts here, they save instantly to this browser, so "Preview Site" shows them right away.
2. When happy, press Publish, Download posts.js and replace the file at assets/data/posts.js in the website folder with the downloaded one. That makes the posts live for everyone.

PDFs (e.g. catalogs): copy the PDF into the assets/pdfs/ folder, then type its path below, visitors get a download button and an inline preview.
Videos: paste any YouTube link, it embeds automatically.
